# Everyday Calculator Hub

A simple static website with free everyday calculators.

## Included
- Percentage Calculator
- Tip Calculator
- Discount Calculator
- Sales Tax Calculator
- Average Calculator

Built with plain HTML, CSS, and JavaScript. No external libraries required.

## GitHub Pages
Upload the files to a GitHub repository and enable GitHub Pages.

Before publishing, update the canonical URL in `index.html` to your actual GitHub Pages URL.
